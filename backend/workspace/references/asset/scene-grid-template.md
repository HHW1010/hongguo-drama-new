# 场景地点板（红果图面 · 广角空镜 · 无人物）

> 归属技能：asset（资产锁定）。本文件是场景参考图最终提示词的权威细则。
> 图面纪律（红果）：**广角空镜地点板（location plate）**——纯场景空镜、**完全没有人物**、完整交代入口/路线/固定锚点及其相对关系，空间结构连续、自洽、可复用。这张图是后续该场景所有镜头的地理锚点。

## 一、总则：地点板是地理锚点

生成的是一张**广角空镜地点板（location plate）**：**完全没有人物**的纯场景空镜，完整交代**入口、路线、固定锚点及其相对关系**，空间结构连续、自洽、可复用。观众和模型都必须能从这张图读懂空间的布局：从哪里进出、地面墙面什么质感、核心陈设各自固定在什么位置。

作为参考图挂到镜头时，其 `用途` 是 **`地理`**（可控制：入口、区域、固定锚点、方向关系）。

## 二、地理锚点落地（硬约束）

场景 `prompt`（空间陈设）与 `lighting`（光影）里的关键地理事实必须逐项落进正文：

- **逐项落进正文**：出入口位置与样式、固定锚点、方向关系（如「画面左侧一扇铁门」）不得漏、不得改；
- **不得新增字段里没有的结构**（不加锚点外的门、窗、房间）；`lighting`（光影）按资产字段具体化。

## 三、地理优先写法（硬约束）

先画「文字地图」：从哪个入口看向哪个方向，前/中/后景分别是什么，关键锚点在彼此哪一侧，人物可能从哪里进出。**用「两两关系 + 视线终点」而非无序罗列**，例如「从卷帘门向内看，检修台沿右墙延伸，尽头唯一安全门正对通道」。只有与识别、调度或连续性有关的结构进入正文。

必填层次：

1. **身份与功能**：这是什么空间、服务什么活动、整体尺度
2. **View 与方向**：观察位置、朝向、可见边界；给左右以画面/场内参照，避免「左边」含义漂移
3. **入口与路线**：门、走廊、楼梯、通道在哪里，彼此如何连接
4. **固定锚点**：柜台、柱、窗、机器、壁炉等不可移动物及相对关系
5. **材料与色彩**：墙/地/顶、磨损、主次色
6. **当前 state**：摆设、时间与光线变化（临时 dressing 不写成永久地理）

## 四、输出结构（按此顺序组装单段连贯描述，语言跟随会话语言指令）

```
固定机位广角空镜，地点板，[地点 + 年代质感]，[时间段]，
[从入口看向方向：前景→中景→后景的三层纵深与视线终点]，
出入口（[门/通道的位置与样式，含地理锚点]），固定锚点（[不可移动物及其相对关系]），
地面（[材质与状态]），墙面（[材质与颜色]），
[主要陈设及其固定相对位置]，空间结构连续、自洽，
[光源方向 + 色温 + 明暗对比]，[氛围]，画面中没有任何人物，空场景
```

## 五、人物（硬性规则 · 最高优先级）

**场景图中不能出现任何的人，只保留场景本身。**

- 提示词中不描述人物、不提及任何与人物相关的内容
- 场景描述（prompt）中出现的人物信息一律忽略，不写入提示词
- 提示词结尾必须包含："画面中没有任何人物，空场景"

## 六、光线连续性与气氛

- 说明主光来源与方向、时间/天气关系、实际灯具及需要保留的暗区，不要只说「电影光」
- 同一 Location 同一时间/天气 state 下的各块板，共享同一套主光来源、色温关系与光比方向
- 气氛词具体化："压抑" → "空气闷热、光线昏暗低沉"，不写抽象情绪词；不得为气氛新增剧情事故、封锁出口或移动固定结构
- 输出使用会话语言指令指定的目标语言，不要混入无关词汇

## 七、视角与禁止事项

- 稳定的平视或微俯广角，不要极端俯仰、鱼眼、倾斜构图（要作为固定场景反复复用）
- 任何人物——**场景图中不能出现任何的人，只保留场景本身**
- 文字、招牌上的可读文字、水印、签名
- 动态模糊、运动中的物体（场景参考图必须静止稳定）
- 只罗列陈设清单而不交代相对位置（空间结构必须连续、自洽）
- 正文里出现 `IMG-`/`REF-`/`LOCK-` 等元数据（那些只写在回复的 `IMG-…` 条目里）

## 八、保存

调用 `save_scene_final_prompt`：`prompt` 参数放这条**干净的可复制正文**（不含元数据）。项目视觉风格会由工具自动注入到最前方。回复中同步给出该场景板的 `IMG-…` 条目（用途：地理）。
