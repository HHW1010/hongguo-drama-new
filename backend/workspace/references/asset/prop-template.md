# 道具参考图板式（红果图面 · 三视图道具板 / 四视图设计板 / 正视图单品）

> 归属技能：asset（资产锁定）。本文件是道具参考图最终提示词的权威细则。
> 图面纪律（红果）：
> - 默认 → **三视图道具板**（同一画布三个正交视图：正面 / 侧面 / 背面，横向等距、底部对齐同一水平基准线）
> - 勾选四视图（`sheet_mode=four-view`）→ **四视图设计板**（横版 16:9 2×2 均等：SIDE / FRONT / TOP / 3-4 VIEW）
> - 勾选正视图（`sheet_mode=front-view`）→ **正视图单品**（单一正视图，正对镜头、居中完整入镜）
> - 禁人物 / 手 / 肢体入画。

## 一、总则：道具板是识别锚点

生成的是一张道具设计参考图，**板式由「视图模式」决定**，它是后续所有镜头里这件道具的识别锚点：

- **默认 → 三视图道具板**：同一画布中仅三个正交视图——正面 / 侧面 / 背面，横向等距排列、底部对齐同一水平基准线。
- **勾选四视图（`sheet_mode = four-view`）→ 四视图设计板**：横版 16:9 + 2×2 均等宫格——SIDE / FRONT / TOP / 3-4 VIEW。
- **勾选正视图（`sheet_mode = front-view`）→ 正视图单品**：单一正视图，正对镜头、居中完整入镜。

**核心原则：识别 > 美观。** 这张图让后续画面保持同一件物体的轮廓、尺度、材料、功能和当前状态；视图数量不是道具身份的一部分，按复用需要选。

## 二、识别锚点落地（硬约束）

道具 `description` 里最有辨识度的特征必须逐项落进正文：

- **逐项落进正文**：固定形制、配色、材质、尺寸、裂纹/磕角等跨镜不变的标记不得漏、不得改；
- 亮屏/熄屏、开合、湿污、破损程度这类**会随剧情变化**的写 `造型状态`，不当作身份锚点；
- **不得新增描述之外的特征**（不加描述没有的纹样/配件）。

作为参考图挂到镜头时，其 `用途` 取 **`身份`**（固定的形制、配色、裂纹、磕角这类跨镜不变的识别标记）或 **`造型状态`**（亮屏/熄屏、开合、湿污、破损程度这类随剧情改变的状态）；两者都需要固定时拆成两个槽位。

## 三、固定三视图正文（默认，硬约束）

每条基础道具板的可复制正文，必须**逐字加入以下要求**（`〈…〉` 处用 `name`/`description` 的材质/颜色/形状/大小/磨损/识别锚点填充，其余固定句逐字保留）：

```text
同一画布中仅包含三个正交视图：正面视图、侧面视图、背面视图。三个视图横向等距排列，底部/最低点对齐同一水平基准线，高度、宽度、厚度、结构比例和部件位置完全一致，误差不超过5%。背面视图完全背对镜头180度，侧面视图为90度侧面，正面视图正对镜头；各视图保持材质、颜色、图案、接缝、磨损、配件、RGB颜色一致。采用正交投影，道具静止展示，禁止透视变形、仰视、俯视、倾斜视角、动态角度。统一正面平光，柔和均匀照明，避免侧光阴影差异。纯白色背景，无渐变、无纹理、无装饰元素。高清细节，产品级渲染。画面中不要出现任何文字说明、标签、尺寸标注、箭头或额外布局。

道具主体：〈道具名〉，〈材质/颜色/形状/大小/新旧程度与磨损细节，逐项含识别锚点〉。三个视图分别呈现：正面视图〈正面可见结构/配件〉；侧面视图〈侧面轮廓与厚度/活动部件〉；背面视图〈背面结构与接缝/扣件〉。
```

## 四、固定四视图正文（勾选四视图，硬约束）

勾选四视图（`sheet_mode = four-view`）时**不写三视图正文**，改用下面的四视图设计板骨架；同样逐字组织、仅替换 `〈…〉` 槽位，不得混入三视图的横向排列/纯白背景/平光要求。

```text
一张道具设计参考图（四视图设计板）。横版 16:9 比例。最高分辨率输出。纯色中性浅暖灰摄影棚背景。单侧侧轮廓背光，从相机右侧 45 度位于主体后方，无补光，无正面光，无其他光源——戏剧性电影感造型册灯光。

【布局】2x2 均等网格：左上 SIDE VIEW（纯正侧视，主视图）、右上 FRONT VIEW（正视，突出正面特征）、左下 TOP VIEW（俯视，展示顶面与占地轮廓）、右下 3/4 VIEW（四分之三透视，展示体积与纵深，hero shot）；四格之间用细中性浅灰分隔线；道具居中于每格，留均匀边距。

【主体——4 格中同一道具】道具主体：〈道具名〉，〈材质/颜色/形状/大小/新旧磨损，逐项含识别锚点；含结构/部件/可动部位说明〉。

【4 格细节】左上 SIDE VIEW：纯正侧视，主体朝向画面右侧，全貌可见，〈侧视轮廓/厚度/活动部件〉。右上 FRONT VIEW：正对镜头，〈正面特征/部件〉居中。左下 TOP VIEW：正上方俯视，〈顶面布局/占地轮廓〉最清晰。右下 3/4 VIEW：约 30-45 度前侧、略抬高视角，侧视+正视+俯视同时可见，〈体积纵深〉，hero shot。

【关键一致性】4 格中同一道具——相同比例、材质、配色、部件位置、磨损；共用同一背景与单侧侧轮廓背光。

【灯光】单侧侧轮廓背光，从相机右侧 45 度位于主体后方；无补光、无正面光、无环境光、无其他光源；强边缘光勾勒主体右侧剪影。

【风格】〈项目视觉风格：取 drama.visual_style 的中文名与描述〉。

【质量】最高分辨率输出，干净锐利边缘，每个结构、接缝、材质细节清晰定义。

【分格标签】每格下方小型干净等宽无衬线黑色文字：左上"SIDE"、右上"FRONT"、左下"TOP"、右下"3/4 VIEW"；画布顶部居中标题："〈道具名〉 — DESIGN SHEET"。

【约束】不是三视图横向排列（四格 2x2 均等）、不是 1:1 方形（必须横版 16:9）、不是彩色背景（仅纯色中性浅暖灰）、不是柔和均匀中性灯光（必须仅单侧轮廓背光）、除四格标签和标题外无任何其他文字。
```

## 五、固定正视图正文（勾选正视图，硬约束）

勾选正视图（`sheet_mode = front-view`）时**不写三视图/四视图正文**，改用下面的正视图单品骨架；同样逐字组织、仅替换 `〈…〉` 槽位，不得出现侧面/背面/俯视。

```text
一张道具设计参考图（正视图单品）。横版 16:9 比例。最高分辨率输出。纯色中性浅暖灰摄影棚背景。单侧侧轮廓背光，从相机右侧 45 度位于主体后方，无补光，无正面光，无其他光源——戏剧性电影感造型册灯光。

【构图】单一正视图：〈道具名〉正对镜头，完整居中入镜，留均匀边距，无侧面/背面/俯视。

【主体】道具主体：〈道具名〉，〈材质/颜色/形状/大小/新旧磨损，逐项含识别锚点；正面可见结构/部件〉。

【风格】〈项目视觉风格：取 drama.visual_style 的中文名与描述〉。

【标题】画布顶部居中标题："〈道具名〉 — FRONT VIEW"。

【约束】不是三视图/四视图/多视图（仅单一正视图）、不是侧面/背面/俯视、不是 1:1 方形（必须横版 16:9）、不是彩色背景（仅纯色中性浅暖灰）、不是柔和均匀中性灯光（必须仅单侧轮廓背光）、除标题外无任何其他文字。
```

## 六、生成规则

- 以 `name`（名称）与 `description`（含识别锚点/外观）为核心：材质、颜色、形状、大小、新旧程度、磨损痕迹等物理细节**逐项落地**
- 三个视图是同一件物体，比例/材质/细节完全一致，误差不超过 5%；正交投影、静止展示
- 纯白背景，只作为衬底，不承载任何叙事内容；无其他物品、无人物、无场景、无手部持握
- 道具本身若有已接受的标识、屏幕或铭文，按 `description` 的文字政策保留或说明承载面，不因「不要出现任何文字说明」误删道具原生文字
- 输出使用会话语言指令指定的目标语言，不要混入无关词汇；**不要**"电影质感"类词汇（道具板是设计图不是剧照）

## 七、禁止事项

- 手部持握、人物、其他物品、场景环境入镜
- 包装、底座、展示架（除非它本身就是道具本体的一部分）
- 透视变形、仰视/俯视/倾斜视角、动态角度、比例失真、边缘裁切
- 渐变/纹理/装饰背景、环境反光、彩色光
- 正文里出现 `IMG-`/`REF-`/`LOCK-` 等元数据（那些只写在回复的 `IMG-…` 条目里）

## 八、保存

调用 `save_prop_final_prompt`：`prompt` 参数放上面这条**干净的可复制正文**（含固定三视图要求，或勾选四视图/正视图时含对应固定要求；不含元数据）。项目视觉风格会由工具自动注入到最前方。回复中同步给出该道具板的 `IMG-…` 条目（用途：身份或造型状态）。
