# 资产锁定规范（sd-asset-engine）

本技能是「资产锁定」阶段的详细规范。你把原始文本翻译成「可出图的资产提示词 + 编号 + 《素材接线单》」，产出通过工具落库。权威细则文件在 `references/`（`three-list-extraction.md`、`scene-grid-template.md`、`character-portrait-templates.md`、`fourview-sheet/`（四视图人设图 3D CG 规范）、`prop-template.md`、`continuity-and-crowd.md`、`asset-delivery-modes.md`）。

## 一、三清单提取（`references/three-list-extraction.md`）

人·物·场分离、不重复。原文优先，推导补充须标注。

- **角色外观六要素**：年龄 / 性别 / 肤色 / 发型发色 / 五官特征 / 服装（整段文字）。性格转化为外在气质融入样貌，不单独输出性格字段。
- **独立道具设计清单**：只提取直接推动剧情且值得单独出图的关键道具（0-3 个）。判定三问任一答"否"即放弃：删掉它剧情依然成立吗？它只是随手日常物品吗？它是场景陈设吗？
- **独立场景设计清单**：正面全景微俯视大白话 + 空间要素分析。`prompt`（空间陈设）+ `lighting`（光影）。

## 二、素材形态（`references/asset-delivery-modes.md`）

| 形态 | 名称 | 图在哪 | 提示词写法 |
|---|---|---|---|
| M0 | 纯提示词 | 哪都没有 | 不出现任何图号，文字锁兜底 |
| M1 | 编号占位（默认） | 用户平台侧 | 图号槽位 + 必附《素材接线单》 |
| M2 | 已入库 | 用户交回 | 图号槽位，可图像级核验 |

- 默认 M1；用户说「我没有图/只要提示词」→ M0；用户交回图 → M2。
- **四铁律**：不索要图片 · 不因缺图阻断 · 不写不存在的图号/不假称已核验 · 每次声明形态。
- 形态通过 `material_form` 字段落库；M0 时 `asset_code` 置空。

## 三、图面纪律（红果）

### 角色（`references/character-portrait-templates.md` + `references/fourview-sheet/`）

- **默认（所有角色）→ 正视图立绘**：竖版 9:16 单格全身正面，不做多视图；规范与四视图一致（纯白色背景、无灯光 + 3D CG 风格内嵌 + 底部「FRONT」标签与顶部标题），正文**由工具自动拼装**，你**无需手写正文**。
- **勾选「四视图」（`sheet_mode=four-view`）→ 四视图人设图**：竖版 9:16 2×2 不等大（左上正脸特写 / 右上侧脸特写 / 左下脖子以下正面无脸 / 右下背面含后脑勺），四格同一角色。提示词正文**由工具自动拼装**（fourview-sheet 3D CG 母版：纯白色背景、无灯光 + 四格面板标签与顶部标题 + 英文正文 + 3D CG 风格内嵌），你**无需手写正文**，调用 `save_character_final_prompt` 时 prompt 传一句简短说明即可。
- **勾选「脸部放大-三视图」（`sheet_mode=face-three-view`，不限功能位）→ 脸部放大三视图**：横版 16:9 左 1/3 面部特写 + 右 2/3 三视图（Front/Profile/Back）。
- **脸部放大三视图**板式：纯白色背景、无灯光、**画面内不出现任何文字、标签、标题、水印**。

### 场景（`references/scene-grid-template.md`）

- **地点板**：固定机位广角空镜，地理优先，完整交代入口/路线/固定锚点及相对关系；**画面中不能出现任何的人**，空场景。

### 道具（`references/prop-template.md`）

- **默认 → 三视图道具板**：正面/侧面/背面三视图横向等距、底部对齐同一基准线，纯白背景平光。
- **`sheet_mode=four-view` → 四视图设计板**：横版 16:9 2×2 均等（SIDE/FRONT/TOP/3-4 VIEW），纯色中性浅暖灰背景 + 单侧轮廓背光。
- **`sheet_mode=front-view` → 正视图单品**：横版 16:9 单一正视图。
- 禁人物/手/肢体入画。

### 音色（manju-laoli · 不进图）

- 每个角色配 `voice_description`：**根据剧本生成该角色的音色**，英文 2-4 句，覆盖音色特质/语速语调/情绪层次/适用场景（参考 manju-laoli-skill：https://github.com/lixiaoxiao9888-create/manju-laoli-skill）。
- **逐角色推导、不照抄示例**；示例只是样式范本。
- `voice_description` 是**纯文本字段**，**不写进角色参考图**（红果图面零文字）。

### 人物特征（traits · 不进图）

- 每个角色配 `traits`：**先调用 `read_drama_plot` 读取整部剧全部剧情原文**，据此把握该角色整体人设与剧情弧光，生成「人物特征」。
- 格式五段式、全角分号「；」分隔、整段包在【】内：`【名字：年龄/外形；性格气质；行为表现；音色；语言风格】`。
  - 第一段 年龄/外形（如「18-20岁左右」；非人类/系统音写外形，如「外形6-8岁小女孩感」）
  - 第二段 性格气质（如「温和开朗、亲近自然」）
  - 第三段 行为表现（如「行为松弛，笑意多，动作自然亲昵」）
  - 第四段 音色（如「温润青年音，明朗、亲和、带一点笑意」）
  - 第五段 语言风格/口音（如「标准普通话，轻松自然，不需要太端着」）
- 与最终提示词同一次 `save_character_final_prompt` 调用里用 `traits` 参数保存；**逐角色推导、不照抄示例**。
- `traits` 是**纯文本字段**，**不写进角色参考图**（红果图面零文字）。

## 四、《素材接线单》（`references/asset-delivery-modes.md` §四）

表头：`图号 | 类型 | 用途（只控制什么） | 你该挂哪张 | 不控制什么`。

- 每个图号必须写明「只控制什么/不控制什么」。
- 接线单与提示词图号**双向一致**。
- M1 交付必附（通过 `save_asset_ledger` kind=wiring_sheet 落库）。

## 五、硬性纪律

- 提示词正文只装画面语言，编号（图N）只出现在标题/接线单，正文不写「图〔N〕」字样。
- 人物立绘纯净 no pose：只呈现人物本体+穿戴，禁手持/放置独立道具，端正站立。
- 命名逐字一致：去重保存、最终提示词、接线单三处同一写法。
- 只产出可落库数据，不输出规划/分析文本。
