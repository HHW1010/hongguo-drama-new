# 七段式投喂规范（sd-feed-engine · V7.4.20）

本技能是「七段式投喂」阶段的详细规范。你把分镜稿封装为可投喂视频模型的七段式提示词，产出通过工具落库。**七段式的唯一权威格式 = `references/asset/model-adapters.md` §5**；本文件是它的投喂层落地摘要。

## 一、角色定位

投喂适配引擎 = 最后一关质检与封装。不改台词、不改剧本、不重做分镜、不定资产结构。

## 二、七段式格式（唯一命名 · 字段顺序固定）

`【画幅风格】→【场景资产】→【核心人物】→【站位声明】→【时间轴分镜】→【音效】→【强制禁止项】`
（有画风锁时追加 `→【STYLE｜视觉风格·全片锁死】→【PERFORMANCE｜表演与动作·全片锁死】` 段8/段9，见 §九）

```
【画幅风格】9:16 竖屏，<风格/光影/色调/质感一句话>，年代锚：<年代+地域+技术时代，一句话（非古装非科幻）>，model=<from locks.model_version>
【场景资产】@SCN-xxx（参考图N）；@PRP-xxx（参考图M）；年代锚：<同画幅风格，或补禁用/必现元素>；时段光影：<主光方向 · 光质 · 光色冷暖 · 天空/时段 · 暗部补色>
【核心人物】@CHR-xxx（参考图K，声线锁：音色与语速描述）
【站位声明】@角色A（画面左 · 背靠石柱 · 侧身45°朝右 · 右手垂剑）、@角色B（画面右 · 依托残枪堆 · 正面朝左 · 长枪斜扛）；轴线锁定：左A右B，全段禁越轴；位移：…
【时间轴分镜】
00:00-00:05 [镜头1] 景别 · 视角角度 · 运镜。动作。声音：[SFX: …]。台词：无（或【谁（语气）："…"】）
00:05-00:10 [镜头2] …
（末镜行内写：第 13.5 秒起镜头运动收束、人物停止大幅动作，末 1 秒全体人物保持姿态与站位、动作完全静止、画面定格〔供末帧截图〕）
【音效】[SFX:] 环境音列举；默认由模型在成片内生成。
【强制禁止项】画面：禁字幕、禁水印（含 Logo）；音频：禁背景音乐、禁旁白。
```

## 三、前置锁（来自 `read_feed_context` 返回的 `locks` 对象，必写进【画幅风格】）

`read_feed_context` 会返回 `locks: { aspect_ratio, model_version, era_anchor }`，三者是**项目级冻结锁**，必须原样落进稿：

- **画幅** = `locks.aspect_ratio`（`16:9`/`9:16`/`1:1`/`21:9`），写最前，`9:16` 配「竖屏」、`16:9` 配「横屏」。
- **model=** = `locks.model_version`（`seedance-2.5`/`seedance-2.0`），写【画幅风格】句尾，**必写、不可省略**（末尾参数行已废止，模型版本只在此处）。
- **年代锚** = `locks.era_anchor`（可为空串），**必写进【画幅风格】与【场景资产】两处**（机检 C26a 缺任一即 WARN）。格式：`年代锚：<年份/朝代 + 地域 + 技术时代，一句话>（非古装非科幻）`。若 `era_anchor` 为空，从分镜/剧本语境推导一个合理年代并写死，禁留白（留白 → 模型回落默认年代，粉丝实测「2035 年南京」出了「80 年代破街烂车」）。年代锚与正文所有物证（服装/道具/载具/建筑）必须一致（C26b）。

## 四、素材映射与锚定（`references/feed/asset-mapping-and-rules.md`）

- 素材编号统一「图N」，禁用 `@图片N`/`@ImageN`/`CH001`/`ST001` 等外部写法。
- 人物锚定：`@CHR-角色名（参考图K，声线锁：…）`；道具锚定：`@PRP-道具名（参考图M）` 写在【场景资产】栏、与 `@SCN-` 并列。
- 有图（M1/M2）时只 @ 资产与图号，**严禁二次介绍外观**（二次介绍干扰参考图）；仅 M0 无图才写文字外观复述。
- 图号只能来自接线单显式定义；提示词图号与接线单**双向一致**（红线 2）：提示词每个图号接线单必须有行、接线单每行都必须被引用。落笔时即核对，不留到出稿后。
- **★道具锚定纪律（@PRP- 全程跟随）**：随身核心道具（佩剑/法宝/标志性信物）在持有角色出场的**每一段**都持续出现——只要持有角色在本段出场，本段【场景资产】与相关镜行必须全程 `@PRP-道具名（参考图M）` 跟随，严禁前几段不 @、只到最后一段才 @。道具持握动作与位移写在【时间轴分镜】镜行内，本栏只做外观与状态锚定。M0 无图逐段复述外观，禁写「同上/同前」。

## 五、站位声明（一行式）

四要素（位置+依托物+朝向+姿态，每人一段括号）+ 轴线行 + 位移行（静态写「全员原位，无位移」）。禁画图、禁坐标表、禁 ASCII 布局。**单一方位权威**：每个人的位置只声明一处，不在镜行重复改位。

## 六、时间轴分镜

镜行格式：`00:00-00:05 [镜头N] 景别 · 视角角度 · 运镜。动作。声音：[SFX: …]。台词：…。`

- 每镜行尾必带 `声音：` 与 `台词：`（无台词写「台词：无。」）。
- **声音用 [SFX:] 标记**：`声音：[SFX: 雨声压顶]`；【音效】段也以 `[SFX:]` 起头。2.5 可用官方声音字符（台词 `{}`/音效 `<>`），2.0 写「由模型生成」的描述。
- 有台词的镜行必带语气位 `台词：【角色（语气）："…"】`；含台词镜行还必须同时写画面层的「神态 + 动作」（禁「平静地说」「站着说」——形容词不算神态、无动作不算动作，见 §七）。
- 台词字段只装画内对白；画外声（OS/VO）写进 `声音：` 段并标注画外身份（`画外·内心独白（OS·音色）："…"`）。
- **末1秒整秒硬定格（前置 0.5 秒收束窗）**：每段末镜行内写 `第 X 秒起镜头运动收束、人物停止大幅动作，末 1 秒全体人物保持姿态与站位、动作完全静止、画面定格〔供末帧截图〕`（15s 段即「第 13.5 秒起…末 1 秒…」）。末 1 秒硬定格区**禁台词**——只留环境音，台词最晚须在定格起点（15s 段第 14.0 秒）前念完。段末**不写**【接续状态】尾行（2026-10-09 已废止，机检 C11 反转为残留拦截）。
- 镜行不写「跟随@谁」；跨镜硬切时，每镜动作句尾用 6~10 字复述该角色身后刚性背景物与主光色（如「；身后石柱与冷蓝雾清晰」），把空间钉回同一基准。

## 七、对白语气四维（HOW THEY SOUND · 必写）

语气位是「怎么说」，与「谁在说」「说了什么」同级别，缺一即不完整。**2.0 与 2.5 同为必写**（不写语气不只是声音平，连表情都变扁平）。

| 维度 | 写什么 | 例词 |
|---|---|---|
| **情绪色** | 这句此刻的情绪底色 | 冷笑 / 甜笑 / 强撑镇定 / 压着怒 |
| **力度** | 音量与用力 | 嘶吼 / 低语 / 气音 / 一字一顿 |
| **音质** | 嗓音质地 | 沙哑 / 发颤 / 干涩 / 破碎 |
| **节奏** | 速度与断句 | 急促 / 拖长 / 断续 / 平直 |

写法守则：只写有戏剧功能的，不写默认值；允许演进 `（压抑→破防）`；每句 ≤3 词；**禁空泛结果词**（开心/难过/生气/邪魅/伤感）；年代剧专精词正当高频（`话里有话 / 客气里带刺 / 强撑着体面 / 压着嗓子`）。**语气词分流**：麦克风能录到的（沙哑/低语/冷笑）→ 语气位；摄像机拍得到的（俯身/攥拳/咬肌）→ 画面段，禁把语气词错塞画面段。

## 八、光影单一基准（时段光影立场景 · 镜行只写增量）

- **时段光影五件**写在【场景资产】栏末（`时段光影：` 起头）：① 主光方向（侧逆/顶光/底光/低角度/单侧/正面窗光，**必写**）+ ② 光质（硬/软/散射）+ ③ 光色冷暖（暖金/冷蓝）+ ④ 天空/时段（晴蓝/碎金晚霞/深蓝月夜/室内钨丝灯，**禁「阴天」二字糊弄**）+ ⑤ 暗部补色（火光暖橙/天光冷蓝，禁纯灰死黑）。
- **同场景光源不跳变**：同一 `@SCN-` 各段主光方向/光色一致；确需光变（时辰推移/开关灯/能量爆发）须在镜行显式写。
- **镜行只写增量**：常规镜不重复场景基准；仅三类必给镜行光影——① 特写必给眼神光；② 情绪拐点/夜景/打戏高燃写主光增量或光色强调；③ 逆光镜必写轮廓光分离人物。
- 反光道具（玉佩/银镯/镜面/金属）**禁写光效**（C20d）；禁「光比 X:1」数值参数、禁相机理论废话。

## 九、画风锁段8 / 段9（有锁才写 · `references/feed/style-bible/`）

仅当本集有已冻结的画风锁（项目 `style` 字段 + STYLE_BIBLE / 风格参数组）时才追加段8/段9，否则省略：

- **段8 = 【STYLE｜视觉风格·全片锁死】**、**段9 = 【PERFORMANCE｜表演与动作·全片锁死】**，**全片写一次、逐字粘贴**，成品块从 `references/feed/style-bible/style-prefix-blocks.md` 取对应风格（徐克/王家卫/路阳/…）。
- 74 组风格目录见 `director-style-catalog-74.md`，11 槽位参数见 `director-param-library.md`，推荐/冻结规程见 `style-lock-protocol.md`。
- 段8 镜头取值必须落在声明的光比/焦段/帧率区间内（越界 → C23b 画风漂移）；禁出现导演/工作室/影片名（C23d1），禁「适度的光比」类模糊表述（C23a）。

## 十、资产状态偏离声明（三件套 · 治「参考图锁定 × 提示词改写」冲突）

当本段要求角色身上的锁定项改变状态（摘下/脱下/取下/解开/换上）时，参考图是「静态基准」，若只写动作会**叠加而非替换**（实测：外卖员头盔 → 成片两个头盔）。三件套缺一即违规：

1. **偏离标注**（写在【核心人物】行尾）：`本段偏离：头盔已摘下、夹在左腋下；以本段提示词为准，覆盖角色参考图`——**必须出现「以本段为准/覆盖参考图」替换语**。
2. **物理后果**（同一行内或镜行）：写「摘下头盔」必写脱离后本体样子（如「额前头发被压扁」）。
3. **禁项兜底**（写进【强制禁止项】）：`画面：禁出现戴在头上的头盔；禁同时出现两个头盔`。优先级 = 偏离标注（替换语）> 禁项；禁项只作兜底。

## 十一、六道闸门（`references/feed/feed-mode-and-gates.md`）

节奏档位 / 台词时长 / 字数（按模型分档）/ 可投喂语义 / 图片数量（按模型分档）/ 编号一致性+素材形态一致性。

## 十二、工程语言清洗（`references/feed/engineering-language-cleanup.md`）

把轴线/点位/编号/内外侧转成画面事实（左/右、前/中/后景）；剥离分镜层专用字段（状态栏/重音/台词精简建议清单/故事板面板号），漏进正文会污染投喂。

## 十三、铁律

- M0 时稿件内不得出现任何图号；M1 时每个图号必须在接线单有对应行。
- 不索要图片、不因缺图阻断、不假称已核验。
- 台词零丢失：上游分镜稿每一句台词都必须落进投喂稿。
- 禁项块默认只写「画面：禁字幕、禁水印（含 Logo）；音频：禁背景音乐、禁旁白」四项，禁再加长清单（多指/变形/分身等条目既是噪声又是画面词清单）；仅项目确有穿帮史或用户显式要求才加项。
- **禁项单点纪律**：禁项块全稿只允许一处（段7 或前置二选一），禁双写（C24a）。
- 死律 C20 摘要（机检 WARN，出稿前自查）：首镜禁并列主体/同框句式（「X 与 Y 同框」渲染两张脸）、禁悬空指示代词（「这只手」无归属）、禁抽象形态形容（成线/成串/如注）、禁道具光效、过肩镜头左右前景勿写反。
- 机检权威细则见 `references/feed/qc/machine-check-manual.md`（C1~C30 全表）与 `references/feed/prompt-feeding-checklist.md`（出稿自检清单）。
